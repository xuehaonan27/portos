# PortOS Documentation

This directory holds the refined documentation of PortOS. Short, accurate
documents that describe the current state of the system. The working corpus
(design volumes, decision records, status notes) lives in `.dev/`. Documents 
graduate here after review.

## Reading order

1. [overview.md](overview.md) — what PortOS is, why it exists, how the
   workspace is laid out, and where development currently stands.
2. [resource-model.md](resource-model.md) — how PortOS models, accounts
   for, and governs resources: the four-module declaration, the central
   ledger, verb kinds, budgets, monitors, and the six decisions F1–F6.
